How updates keep flowing when a report is open in Excel

Every job that writes into a workbook follows the same safe-write algorithm, so an analyst having the file open never blocks new data.

  1. 1Compute & queue. Loggers (dgr_update, dor_update) read fresh readings from MySQL and stage them in a JSON buffer instead of writing straight to the workbook.
  2. 2Check the lock. Before opening a workbook, the writer (dgr_merger, dor_merger, dor_generate, mor_generate) asks the OS whether the file handle is already held open.
  3. 3Open → skip. If it's locked, the write is skipped for that pass and the data stays queued (loggers) or a regeneration flag is set (report generators) - nothing is lost.
  4. 4Retry every 2 minutes. A short-interval cron re-checks the lock and writes as soon as the file is closed, so the workbook catches up automatically without manual re-runs.
